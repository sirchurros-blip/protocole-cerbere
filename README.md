# Protocole Cerbère

Jeu de gestion de la Fondation SCP avec combats de cartes, en une seule page web.
Installable comme application (Windows, Android, iPhone) et jouable hors ligne.

- `index.html` : le jeu complet
- `trailer.mp4` : la bande-annonce, lue depuis le menu (l'entrée n'apparaît que si le fichier est présent)
- `manifest.webmanifest`, `sw.js`, `icons/` : installation et mode hors ligne
- publié avec GitHub Pages (aucun build)

Voir `LISEZMOI.txt` pour l'installation.
